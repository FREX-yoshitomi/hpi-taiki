# 吉富大起の HPI — 構想ページ

> 俺の人生を、ひとつのインターフェースに。

**HPI (Human Programming Interface)** の構想ページ。バラバラのサービスに散らばった自分の人生の痕跡を、ひとつの API で触れるようにする個人プロジェクト。[karlicoss/HPI](https://beepb00p.xyz/hpi.html) に着想を得ています。

🔗 **公開ページ**: https://frex-yoshitomi.github.io/hpi-taiki/

> ※ 個人データのダッシュボード(実際のコミット・活動ログ等)は、プライバシー保持のため公開していません(手元=ローカルでのみ稼働)。このリポジトリには構想ページ 1 枚のみを置いています。
